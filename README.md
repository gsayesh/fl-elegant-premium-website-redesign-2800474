# Ellery & Stone: premium website redesign (two concepts)

"Ellery & Stone" is a placeholder brand for a high-end Australian custom home builder. Your logo, copy and photography replace it one-for-one.

| | Concept A "Light & Stone" | Concept B "Evening Timber" |
|---|---|---|
| Pages | `index.html`, `projects.html`, `about.html`, `contact.html` | `concept-b/index.html`, `projects.html`, `about.html`, `contact.html` |
| Style guide | `styleguide.html` | `concept-b/styleguide.html` |
| Stylesheet | `assets/css/light-stone.css` | `assets/css/evening-timber.css` |
| Fonts | Cormorant Garamond + Manrope | Fraunces + Jost |

Shared: `assets/js/site.js` (menu, sticky header, scroll reveals, project filter, testimonials, form validation), `assets/art/*.svg` (18 vector illustrations in day, dusk and line versions), `assets/css/guide.css` (style-guide layout).

Plain HTML, CSS and vanilla JS with no build step. Open any page from disk or host it as-is. Fully responsive: mobile < 768px, tablet 768–1079px, desktop ≥ 1080px.
Entry boards are in `entries/`.
